A bit about how I work

I'm a Associate Software Developer at Prismforce, where I work on selectprism, A AI-powered recruitment and Interview platform for the hiring managers. My daily tasks involve full-stack development, consisting React and Next.js based Frontend and Nodejs (Typescript) and FastApi (Python) based Backend, with MongoDB as the database and on infra side AWS (EC2, KMS, S3, SNS, SQS, etc.), docker and Redis (for caching).

I like problems where solution involves e2e from FE to BE with a lot of exposure to database and infra side. I'm a quick learner and I'm always looking for new challenges and opportunities to grow. Outside of work I do competitive programming in C++ and contribute to open source when I find a good bug to chase.
