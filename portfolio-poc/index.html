A bit about how I work

I'm an Associate Software Engineer at Prismforce, where I work on SelectPrism — an AI-powered recruitment and interview platform. My day-to-day spans the full stack: React and TypeScript on the frontend, Node.js and Python/FastAPI on the backend, with MongoDB, AWS (SQS, SNS, S3), Docker and Redis underneath.

I like problems where the interesting part is the plumbing — getting data reliably from one system to the next, keeping services observable, and making AI features actually production- ready instead of just demo-ready. Outside of work I do competitive programming in C++ and contribute to open source when I find a good bug to chase.
