Square brackets = WHERE clause. Only the email input matches. ^= $= *= ~= |= are the other operators.

Pseudo-element :: (ghost box)

.quote::before { content: "\201C" }   .card-line::after { content: "" }   ::placeholder   ::selection

CSS does not style the page. It runs queries against a tree.
